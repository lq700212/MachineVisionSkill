当前方案 Token

页面里所有颜色/圆角/间距都必须走这些变量，禁止写死色值；换方案时才能整页无痕切换。

落地映射 · WinForms目标栈

圆角走自绘 GraphicsPath（Region 四角脏边需 AntiAlias + 半像素补偿）；无原生阴影，用双层 Panel；取色统一走 Theme 静态类。

落地映射 · WPF目标栈

换肤用 DynamicResource（StaticResource 切主题不刷新）；DropShadowEffect 只给浮层，大列表会掉帧；矢量布局天然适配高 DPI。
