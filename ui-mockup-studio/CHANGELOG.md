# 更新日志

`ui-mockup-studio` skill 的所有版本变动统一记录在此。格式参考 Keep a Changelog。

## [1.3.0] - 2026-11-18

### 背景

用户反馈一次产出的 A-E 方案"配色、控件设计风格差异不大"，同质化严重，分方案失去
选择意义。根因：内置 5 组 Token 本身同质（a/b/d 主色全蓝系且 b 与 d hex 完全相同）、
差异轴封闭在"密度/圆角/主色/留白"四个数值维度、galaxy 选型全局只做一次、
字体/壳布局/动效全稿写死、check 只数方案数量不查差异度。

### 新增

- **9 基因差异体系**（取代"四维变三"）：色相家族 / 明暗默认 / 圆角形态 / 密度留白 /
  质感手法 / 字体气质 / 强调手法 / 壳层构图 / 动效性格。硬红线：任意两套方案
  10 个基因 Token（primary/primary2/accent/radius/btnradius/gap/pad/fs/font/shell）
  至少 5 项不同；主色跨 ≥3 色相家族、彩色两两色相距离 ≥30°、至少 1 套暖色或中性色。
- **风格基因池（14 原型）**：工业仪表/杂志留白/瑞士网格/终端极客/新拟态软糖/蓝图工程/
  暖色亲和/渐变流体/粗野 brutalism/暗金奢华/霓虹暗夜/玻璃拟态/孟菲斯撞色/极简数字风。
  工作流改为每次抽 5 个互不相同原型 + 每原型独立 galaxy 定向检索产出"基因卡"；
  **出厂 Token 禁止原样交付**，每次按基因卡重校准。
- **壳形态库（同一 DOM，5 种构图）**：`--shell: sidebar/tabs/dock/cmdbar/iconrail`，
  variant CSS 重排 `.app-nav/.app-body`（B 顶栏Tab / C 底部Dock / D 顶部命令条 /
  E 图标窄栏），页面零改动。
- **门面页 `data-layout` 布局分叉**（铁律 2 唯一例外）：≤3 页、每页 ≤3 套布局块，
  纯 CSS 切换（`[data-layout]` 默认隐藏 + variant 显示规则），块内只做容器重排。
- 新 Token：`--font`（每方案字体栈）、`--dur-page/--dur-dlg/--ease-page/--ease-dlg`
  （动效性格，关键帧结构仍全稿共享满足 C13）、`--shell`。
- **check 核验 29 → 33 项**：C23 主色色相家族差异（FAIL）/ C24 基因对差计数 ≥5/10
  （FAIL）/ C25 字体差异（WARN）/ C26 壳层构图差异（FAIL）。

## [1.2.0] - 2026-11-17

### 新增

- **卡片体系（模板内置，卡片式页面唯一写法）**：`.card` 升级为**三段结构**——
  `.card-h` 卡头（图标 + 标题 + 状态）、卡身（直接写内容，不再多包一层）、
  `.card-f` 卡脚（负 margin 通栏贴底，只放动作与汇总）；卡头/卡脚 `flex:0 0 auto`，
  内容再多也不被压扁。新增 `.card-h.band` 通栏卡头（分区卡用，**不叫 `.bar`**，
  避免与项目里 `height:6px` 的进度条同名塌成一条缝）。
- **卡片 Token 族**：`--card-r / --card-pad / --card-gap / --card-line / --card-hi /
  --card-lift / --card-hover-border / --card-well`，五套方案的气质差异只覆盖这几个，
  卡片结构与间距规则一条不动；浅色方案 `--card-line` 单独加深（白卡漂白底上要能看见边）。
- **按职责的 9 种卡片变体**：容器 `.card`、指标 `.card.hero` / `.kpi`、列表
  `.card.pad0 + .card-h.band + .rows`、告警 `.card.rail.ng`、顶线 `.card.top`、
  内嵌 `.card.inset`、瓦片 `.tiles/.tile`、折叠 `.card.fold`、玻璃 `.card.glass`；
  `.card.focus` / `.card.alert` 保留为旧名兼容。同页最多同时出现 3 种卡片语言。
- **规范视图新增「卡片规范」整章**：解剖（真实 DOM）+ 参数表（实时读 Token）+
  六态状态矩阵（默认/悬停/选中/告警/焦点/禁用）+ 按职责的变体语言库。
- **`check_mockup.py` 扩到 29 项**：C19 卡片三段结构、C20 卡片规范章节、C21 职责变体数
  （`--min-card-variants`，默认 6，仅卡片 ≥6 张的稿件触发）、C22 内容区
  `.page`/`.sp-grid` 必须显式 `color:var(--fg)`（防浅色方案白字白底）；
  新增 `--allow-placeholders` 用于核验模板自身。
- **`references/design-playbook.md` 新增第三节「卡片设计原则」**：三段结构、按职责选变体、
  一卡一个语义色、层次靠底色差与 1px 描边、状态六态、卡片规范独立成章；
  后续章节编号顺延（页面骨架→四、方案原理→五、动效→六、破相清单→七、落地→八）。
- **SKILL.md 新增**：铁律 4「卡片式页面必须交付卡片规范整章」（原 4~13 顺延为 5~14）、
  步骤 7.5「真实渲染五坑」（flex 容器 `.tin{flex:1}` 拉空白、`grid-auto-rows` 铺不满、
  跳转图弹窗必须紧跟父页 + 直角总线、文案按真实业务模型、内容区继承 body 文字色致
  浅色白字白底）、步骤 7.6「卡片体系」（三段结构 + 8 种职责变体 + 六态）。

### 修复

- **列表卡行对齐**：`.rows .r` 行高统一 30px、水平内边距 = `--card-pad`，
  与卡头/卡脚同一左缘（原 `padding:8px 2px` 会让整列文字内收一截）。
- **浅色方案白字白底**：模板 `.page` / `.sp-grid` / `.dlg` 显式声明 `color:var(--fg)`，
  不再继承工作台外壳写死的 `#dbe4f0`（AgingTestSystem 实锤，深色下肉眼看不出来）。

### 验证

- `new_mockup.py` 生成到临时目录 → `check_mockup.py` 29 项全 PASS；
  模板自身用 `--allow-placeholders` 核验通过（C15 占位符豁免）。
- AgingTestSystem 真实交付稿回刷：卡片三段结构、浅色方案文字色、跳转图弹窗位置均已按
  本节规则修正后截图目检通过。

## [1.1.0] - 2026-11-16

### 新增

- **双栈落地映射**：`galaxy → WinForms（GDI+/SunnyUI）` 与 `galaxy → WPF（XAML）` 两套。
  模板 `spec` 视图内置两张映射卡，值全部从当前方案的 `getComputedStyle` 实时取 Token——
  切方案/切明暗时两套代码同步变，评审时可直接指着说"这套在我们项目里就是这几个常量"。
  `html[data-stack]` 只决定哪张标"目标栈"并高亮，两套始终都在页面上可对照。
- **`--stack winforms|wpf`**：`new_mockup.py` 生成时直接定目标栈；顶栏可切换；URL 支持 `?stack=`。
- **信息预算（减法硬指标）**：一屏主操作 1 个、按钮 ≤10（硬限 12）、顶栏可点 ≤4、侧栏 ≤7、
  开关 ≤3（硬限 5）、页签首屏字段 ≤8、一行筛选 ≤4、表格行操作 ≤1 个"⋯"、
  页面说明 ≤60 字、单条要点 ≤40 字。超预算必须在右栏写一句为什么。
- **炫点配额**：一屏只允许 1 个循环炫点 C 位（模板示范=相机磁贴扫描光带 4.2s / 主色 13% /
  四块错峰）；表单、表格、正文禁止炫；关掉动效后信息必须仍完整可读。
- **参数与时机**：SKILL.md 新增模式 A/B/C 判定表、步骤 2.5 信息架构减法（先减法再出稿）、
  步骤 3.5 定目标技术栈。
- **`references/simplify-playbook.md`**：原 `ui-simplify` skill 完整并入，并补
  信息预算表、合并五判定、易上手 3 秒/三步/闭眼测试、炫点配额、WinForms 坑位 10 条、
  两栈衔接口径（先减法定架构 → 再出 5 版稿，顺序不能反）。
- **`references/mockup-spec.md`**：data-* 全表（17 个）、类名速查、标准页面/表格页/配置页/
  多状态/三种弹窗可直接粘的片段、完整度清单、预算自检、破相修法、URL 直达表。
- **`references/galaxy-map.md`**：11 分类用途 + 中英检索词表 + CSS → WPF / CSS → WinForms
  两套属性对照、可直接复制的 XAML 样式与 C# 自绘控件（圆角按钮/卡片/开关/动效）、
  两栈落地坑位与选择速查。
- **`check_mockup.py` 扩到 25 项**：C17 `data-stack` 合法、C18 两套映射卡都在、
  W5 页面按钮预算、W6 开关预算、W7 说明字数预算、W8 图标按钮必须有 `title`。

### 变更

- 模板示例按减法改造，自身就是示范：主界面顶栏只留料号+设置（1 入口）、侧栏 7→5 项
