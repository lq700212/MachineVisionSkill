## ⛔ 开发铁律（违反即重蹈覆辙）

1. **先排查清楚，再动手改**。修 bug 前必须走完整数据链核实来源，禁止"印证式确认"
   （拿自己生成的中间产物"验证"自己的推断不是验证；环境事实如目录共享方式必须用
   探针实验实测，不能引用别处文档的结论或单一命令的输出下判断）。
2. **坐标系统一是第一大坑**：pdfplumber / PyMuPDF 的页面坐标 = **顶部原点，y 向下**；
   reportlab = **底部原点，y 向上**。两套坐标混算必错，跨界换算全脚本只允许出现一次
   （`page_h - y`，见盖章步骤5）。改定位/旋转代码前，先在注释里写清当前变量属于哪套坐标系。
3. **写完必实测，三类验证缺一不可**（测试脚本在 `E:\Agent工作空间\视觉方案\盖章测试\`：
   `run_test.py`=常规定位+压平回归，`run_test2.py`=智能定位专项）：
   - **功能回归**：全部定位模式（auto/seal/keyword/default）+ dry-run + `--no-flatten` 跑通
   - **防编辑验证**（本 skill 的核心交付标准）：输出 PDF 盖章页 `page.get_images()`
     必须只有一张整页位图，**不得存在独立公章小图对象**；`page.get_text()` 必须仍能
     搜到原文字（隐形文字层存在）
   - **视觉验证**：盖章页渲染图目检 + 渲染像素对比，印章位置/大小/角度无漂移
4. **关键语义必须写在代码注释+本文档**（如：极坐标展开顶行=外半径；rec-only 为什么要
   分段；平票为什么评分决胜），防止下次迭代因语义误解改坏。
5. **改任何 skill 文件后更新 CHANGELOG.md**（版本号+变更点；版本变动统一记录在该文件）。
   skill 单一副本，改完即生效，无需同步。
6. **诚实降级优于编造**：智能定位任何一步失败只警告并回退常规定位，绝不静默猜位置；
   依赖缺失自动安装（见铁律8），装不上的核心依赖退出并给手动命令。
7. **默认交付形态=不可编辑**：压平（栅格化+隐形文字层）是**默认行为**。任何新功能不得
   悄悄把默认输出退回"可编辑叠加"形态；`--no-flatten` 仅限用户显式要求时使用
   （可编辑输出的公章是独立图片对象，有被移走/抠走/篡改的法律风险）。
8. **新增第三方依赖必须登记依赖表**：脚本顶部的 `REQUIRED_DEPENDENCIES`（核心，
   缺失阻塞启动）/ `OPTIONAL_DEPENDENCIES`（智能定位，缺失自动降级）两张表是
   依赖自动安装机制的唯一依据——新 import 了一个包但没登记，用户机器上就会直接崩。
9. **弱模型等效是每个功能点的验收标准（用户明令固化，迭代时自动执行，无需用户提醒）**：
   本 skill 运行时可能由弱模型驱动——任何功能的设计/改动必须保证"弱模型照抄文档
   就能得到与强模型相同的结果"。每次迭代逐条自检：
   - **判断机检化**：成功/失败/下一步动作由**脚本输出**明确给出（打印"⚠️/→"级提示），
     弱模型只需转述脚本结论，不允许把"模型自己判断"设计成流程的必经环节
     （模型看图/看文档只能作为 `--company`/`--role` 式的可选增强，不能是必需步骤）
   - **流程照抄化**：SKILL.md 的「标准作业流程」必须是命令模板+输出→动作决策表；
     新增/修改任何输出文案（⚠️ 提示、策略名）时，同步检查决策表是否覆盖该输出
   - **兜底提示→照做级**：每个失败分支必须自带下一步指引（如 OCR 失败→提示用
     --company；无盖章栏→提示人工确认），不许只报错不指路
   - **测试弱模型等效**：测试必须一条命令出 PASS/FAIL（run_test*.py 机检），
     "预期表/金标准"由强模型视觉验收一次后固化进测试脚本，此后弱模型复跑同判
   - 自检口诀：**"弱模型拿到这行输出，知道下一步做什么吗？"** 不知道→把指引写进
     脚本输出或 SKILL.md 决策表，才算改完
   - 架构地图、语义表、事故档案同步更新（本条与铁律4重复强调：这是验收项不是文档作业）

数据流：合同文件(PDF/扫描件/图片/Excel) + 公章图 → [Excel: COM 另存为PDF] → [扫描件/图片: OCR规范化] →
智能定位（OCR 公章公司名 → 匹配合同角色 → 定位该角色盖章处；失败逐级回退
seal/keyword/default）→ 尺寸对齐 → 叠加盖章 → **压平** → [图片输入: 渲染回图片]
→ `*_已盖章.pdf` / `*_已盖章.原图格式`。

## 关键语义表（改代码前先对齐认知）

| 概念 | 语义 | 常见误解 |
|------|------|----------|
| 定位模式 auto | 公章OCR→合同角色匹配→三级定位该角色盖章处（默认第一步） | 不是"有参考章就对称盖" |
| 策略1 明确盖章栏 | "需方(签章)："式，盖章/公章/签章×全半角括号全搜 | 只搜"盖章"会漏"需方(签章)"（曾犯） |
| 策略2 列对齐裸签章栏 | "签章： 签章："订购单式，角色块与裸签章块同列配对 | 必须排除其他角色的盖章栏（报价单只有买方栏） |
| 策略2.5 对侧对称 | 本角色无盖章栏但有他角色盖章栏时：章y=他角色盖章栏同高、x=本角色关键字列（报价单"卖方开户行"行，与"买方签字/盖章"上下对齐） | 不是盖在他角色栏里，也不是页面右上公司名旁 |
| 策略3 公司名同行 | 无该角色盖章栏且无他角色盖章栏可对齐时，盖在其公司名文字右侧，输出带"建议人工确认" | 需排除页眉区（阈值10%曾误杀表格首行，12%也不行） |
| 骑压式盖章 | 关键词块宽≥章宽90%时章中心骑在文字块上（模拟真实压字） | 对长签署行仍外排会把章推出文本区贴页边（购销合同曾犯） |
| 页面边界保护 | 章 center 距页边≥8+半章宽，越界自动收进并打印警告 | 所有定位模式通用兜底 |
| 落点禁忌区（动态判断层） | 现场构建"他角色盖章栏+他角色公司名"禁忌区，落点相交则网格搜最近合法位自动挪开；扫描件无文本层→禁忌区空→自动跳过 | 只在智能定位启用；回退模式不知道我方是谁，保持警告交付 |
| 合法压字 | 骑压"本角色"锚点文字（自己盖章栏/公司名/开户行）是真实习惯 | 禁忌区只含他角色元素，本角色锚点永不被避让 |
| 定位模式 seal | 有参考章且 auto 未成功时，左右对称放置 | 不是最高优先级 |
| 定位模式 keyword | auto/seal 都没命中时按"签章/公章"文字块定位 | 回退手段之一 |
| 定位模式 default | 全部失败的**明示兜底**（右下角），有警告输出 | 交付前必须人工核对 |
| --company / --role | 人工兜底通道：跳过 OCR / 跳过 OCR+匹配 | 不是覆盖 auto 的常规用法 |
| ref_content_w/h | 参考章**红色内容区域**的视觉大小(pts) | 不是图片框尺寸（图片框含 padding） |
| 极坐标展开顶行 | =外半径（字头朝外的公章文字展开后正立） | 写反=整行镜像，字符全变反字 |
| rec-only | `use_text_det=False` 直接识别整行 | det 对公章大字失灵，不能依赖 det |
| 按字间隙切段 | 红像素列投影空隙处下刀 | 等宽硬切会把字切两半（"光电"→"光中"） |
| 候选质量评分 | 完整组织后缀+汉字占比+长度合理 | 平票取最长会输给带噪声候选 |
| 压平 flatten | 盖章页整页栅格化 + 重建隐形文字层 | 不是"删除图层"；文字仍可搜索/复制 |
| render_mode=3 | 文字渲染为不可见（隐形文字层） | 不是文字不存在；`get_text()`/搜索/复制都正常 |
| --no-flatten | 保留叠加方式（公章=独立图片对象，可被编辑器选中移动） | 不是推荐用法，仅应急/内部核对用 |
| 输入规范化 | 扫描件/图片 → "整页位图+OCR隐形文字层"规范化 PDF，之后管线与文本版零差异 | 不是新写一套定位逻辑；定位策略只有一份 |
| Excel 转 PDF（v1.2.0） | 调用本机 Excel COM `ExportAsFixedFormat`，等价人工「另存为 PDF」——导出全部可见工作表，保留打印设置/分页/打印区域；Excel 转出的都是文本版 PDF | 不是用 openpyxl 之类 Python 库渲染（无打印设置、版式失真）；"文件可被 pdfplumber 打开"才是写完判据，fitz 会说谎（对残缺 PDF 宽容） |
| Excel 输入输出 | 输出固定 `.xlsx` 同目录 `原名_已盖章.pdf`，默认名以原 Excel 文件（orig_input）为基准 | 不能拿转换后的临时 PDF 路径当基准（否则输出落到 %TEMP%） |
| Excel 无 Office 兜底 | COM 不可用（pywin32 缺失/未装 Office）→ 打印"手动另存为 PDF 后把 PDF 交回盖章" | 不许静默失败；失败分支必须自带下一步动作（铁律9） |
| 扫描件判定 | 每页 get_text 均 <20 字符 | 混合文档（部分页有文字）按文本版处理，定位失败走原回退链 |
| 整页 OCR 引擎 | rapidocr 带 det（RapidOCR()），按行切块识别 | 与公章 rec-only 引擎是两个实例两种用途，不可合并 |
| 图片页面规格化 | 图片输入页面宽=595pts，高等比；渲染回图片按原图宽放大 | 不是 1px=1pt（拍照大图会让默认章宽占比失调） |
| OCR 行写入 | 整行一次 insert_text（render_mode=3），且词宽必须用 get_text_length 缩放到=OCR行框宽（v1.1.1） | 逐词写入会破坏行结构，"需方：A 供方：B"同行正则失效；只按行高推字号会让词宽=字号×字数与行框脱节，定位/宽度过滤全失真 |
| 整页 OCR det 阈值 | box_thresh=0.3 + unclip_ratio=2.0（v1.1.1，提高弱对比签名栏召回）；传 det_* 参数必须显式带 det_model_path=None（新版 API 否则 KeyError） | 默认 box_thresh=0.5 会丢"单位（盖章）/承诺人（签名）："式签名栏整行，关键词定位必落空 |
| max_word_width | 正文行过滤阈值 300pts（v1.1.1，200→300） | 扫描件签名栏整行≈213pts，阈值 200 会误杀；正文贯穿行≥380pts，300 足够区分 |
| 骑压精对齐 | 长行骑压时章中心对齐到命中关键词（"盖章"）在块内的字符位置（kw_words 明细+字符均布估算），无明细退回块中心 | 骑长行几何中心会盖偏半个行宽（实测盖到"承诺人"上而非"盖章"上） |
| 输出覆盖防护 | 输出路径=输入/公章路径 → 拒绝执行 | 图片输入默认输出同格式图片，最易撞名（曾有测试事故） |

## 运行时工作区约定
